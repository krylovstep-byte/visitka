# DOOM Shareware browser bundle

`doom-shareware.jsdos` contains the complete original DOOM v1.9 Shareware
distribution plus js-dos configuration for browser and touch controls.

- Original archive: https://www.gamers.org/pub/idgames/idstuff/doom/doom19s.zip
- Original archive SHA-256: `CACF0142B31CA1AF00796B4A0339E07992AC5F21BC3F81E7532FE1B5E1B486E6`
- Verbatim original archive: `source/doom19s-original.zip`
- Runtime: js-dos `7.5.0`
- Game data: `DOOM1.WAD` (shareware Episode 1), not the registered/commercial WAD
- Browser bundle SHA-256: `18788AA8D8B59809CF0AE23074B0C877ACE68B8221CBF0E4BB06BCE56A4DF96B`

The game files inside the browser bundle are unmodified and include the
original `README.TXT` and FAQ/legal notices. Only the outer archive format and
`.jsdos` runtime/touch-control configuration were added so the DOS release can
run in a browser. The verbatim multipart installer archive is kept next to the
bundle for provenance and preservation of the original distribution.
